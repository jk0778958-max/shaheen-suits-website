Shaheen Suits 👔

A simple and elegant **3-Piece Suit Collection website** created using HTML, CSS, and JavaScript.

📌 Project Overview

Shaheen Suits is a frontend web development project designed for a fictional premium men's fashion brand. The website showcases different 3-piece suits and provides information about the brand and a contact form for customers.

🌐 Website Pages

* Home — Introduction to Shaheen Suits
* Collection — Displays the available 3-piece suits and their prices
* About Us — Information about the brand and its story
* Contact Us— Contact information and a customer message form

🛠️ Technologies Used

* HTML5
* CSS3
* JavaScript
* Responsive Web Design
* GitHub Pages

✨ Features

* Fixed navigation bar
* Premium/luxury visual design
* Suit collection cards
* Hover animations
* Image zoom effects
* Scroll-to-top button
* Animated content
* Brand story video
* Contact form validation
* Responsive layout
